# Abhay Kumar Shukla — Portfolio

Static portfolio website for GitHub Pages.

## Files

- `index.html` — page structure/content
- `style.css` — responsive dark portfolio design
- `script.js` — mobile navigation, reveal animations and dynamic year

## GitHub Pages deployment

1. Create a repository, for example `AbhayShukla1907.github.io`.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save and wait for GitHub Pages to publish.

## Before publishing

Replace the placeholder LinkedIn URL in `index.html` with your actual LinkedIn profile URL.

If you have a PDF resume, add it as `resume.pdf` and change/add a Resume button pointing to `resume.pdf`.
