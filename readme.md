# Abhay Kumar Shukla — Portfolio V2

Detailed static portfolio inspired by modern developer portfolio structure and customized for Abhay's DevOps + AI/ML profile.

## Deploy on GitHub Pages
1. Upload `index.html`, `style.css`, and `script.js` to the root of your Pages repository.
2. GitHub → **Settings → Pages**.
3. Select **Deploy from a branch → main → / (root)**.
4. Save.

## Before publishing
- Replace the placeholder LinkedIn URL in `index.html` with your actual LinkedIn profile.
- Add `resume.pdf` if you want a downloadable CV button.
- Add real GitHub URLs only for projects that are public.
